# Project 4 – Track 1: Smarter Campus
### ML for Occupancy & Space Usage

## Overview

The **Smarter Campus** project explores how Machine Learning and smart sensing technologies can improve the understanding and management of campus spaces.

The goal is to investigate how data-driven approaches can be used to monitor occupancy, analyze space utilization, forecast usage patterns, and detect anomalies, contributing to a smarter, more efficient, and sustainable campus.

The project follows a practical, innovation-oriented approach, moving from ideas and data exploration to the development of working prototypes.

## Main Topics

The project covers the following areas:

- **Cyber-Physical Systems:** Understanding the campus as an interconnected system of physical spaces, sensors, and digital services.
- **Occupancy and Space Usage:** Applying Machine Learning techniques to understand and predict how campus spaces are used.
- **Forecasting and Anomaly Detection:** Identifying usage patterns, predicting future occupancy, and detecting unusual events.
- **Edge AI and Smart Sensing:** Exploring the UNO Q platform, edge sensing, and on-device inference.
- **Integration and Deployment:** Comparing edge and cloud architectures and integrating solutions into working prototypes.

## Project Goal

Develop an innovative prototype that leverages sensing technologies and Machine Learning to make campus spaces smarter.

The final outcome will be presented during the **Demo Day on January 29, 2027**, where projects and prototypes will be showcased.

## Technologies and Tools

The project may involve:

- Machine Learning and data analysis.
- Occupancy sensing and IoT technologies.
- Edge computing and on-device inference.
- UNO Q hardware platform.
- Cloud-based services and deployment architectures.
